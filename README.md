# Idle Capital

An autonomous treasury agent for a business operating across four African
currencies. It decides how much working capital to keep liquid against forward
obligations, and where to park the rest.

> **Status:** in active development for ETHOnline 2026. This README is a stub
> and will be replaced with run instructions before submission.
